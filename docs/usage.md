# PinNote 使用手册

[返回首页](../README.md) · [下载安装](https://github.com/Zhong0118/PinNote/releases/latest)

## 主要功能

- **便签中心**：搜索标题和正文，筛选全部／桌面便签；列表每行显示最后编辑时间（只算标题和正文的修改），默认最近编辑在前。列表行和工作 Tab 都可以拖动重排：按住移动或长按片刻后浮起并跟随指针，其他项让出位置，松手后落入新位置，Esc 取消；拖过之后列表保持手动顺序，新便签出现在最上方，点筛选栏右侧的时钟按钮恢复按编辑时间排序。列表行拖到 Tab 栏会作为 Tab 打开，拖到“放到桌面”会放上桌面。拖动列表右边缘调整宽度（双击恢复默认），宽度会被记住。工作 Tab 过多时使用溢出入口，关闭 Tab 不删除便签。
- **收藏与标签**：标题旁的星标把便签收藏起来，收藏的便签始终排在列表最上方（手动排序和“恢复按时间排序”都不影响）。标题下方可以加标签（最多 12 个，每个不超过 20 个字），列表行会显示前 3 个。收藏和标签只是整理信息，不会和正在编辑的草稿冲突。
- **快速筛选**：筛选栏的漏斗按钮可以只看已收藏、有提醒、有未完成待办的便签，或某个标签下的便签；多个条件同时满足才显示，当前条件以小标签显示在列表上方，点 × 去掉。
- **搜索高亮**：搜索同时匹配标题、正文和标签，命中的词在标题和摘要里高亮；命中在正文靠后位置时，摘要从命中处附近开始显示。
- **历史版本**：更多菜单 →「历史版本」。停下 10 分钟以上再继续编辑时，PinNote 会保留之前的内容；每张便签最多保留 20 个版本。恢复某个版本前，当前内容也会存成一个版本，所以可以再换回来。
- **记录概览**：中心左下角的图表按钮。显示便签数、近 7 天编辑次数、本月完成的待办、连续记录天数、最近半年的热力图和常用标签，点标签直接筛选。统计只在本机进行；AI 工具通过 MCP 做的修改不计入。
- **桌面与中心切换**：放到桌面、定位窗口、收回中心共用同一 ID。桌面便签收起为胶囊或边缘标签时，中心可以直接编辑；独立窗口展开编辑时中心只读，并提供“在这里编辑”把编辑移回中心。
- **中心窗口形态**：中心只有两种常用状态——常规窗口和边缘把手。点标题栏的“收起到边缘”，或把中心窗口拖到屏幕左右边缘（出现提示后松手），就收成边缘把手；点把手、托盘、再次启动或快捷键都会恢复到记住的常规尺寸和位置。把手可以沿边上下拖动并记住位置（按显示器、边和高度比例保存，显示器拔掉后回到主屏）；向内明显拖出时窗口直接出现在指针下。中心可单独置顶，把手跟随中心的置顶状态。紧凑横条只在窗口选项菜单里，作为可选形态。
- **贴边标签**：拖动标题栏握柄或胶囊，靠近左右工作区边缘后松手，便签直接收进边缘槽位，变为一侧贴边的书签式标签。单个标签拖到哪个高度就停在哪个高度；多个标签时，拖到队首会移动整个队列的起点，拖到队列中间只调整顺序。悬停延迟出现只读预览（所有便签共用一个预览窗口）；点击从边缘向内展开，再收起回到原槽位；只有向内拖离边缘才解除停靠。中心把手会避开同侧的标签队列。
- **整理与恢复**：归档、回收站、恢复和移除撤销。恢复先回中心；永久删除仅在回收站确认后执行。归档用来收起用完但还想留着的便签：会被导出、计入统计，提醒暂停。回收站是删除前的缓冲：便签在回收站里保留 30 天（「设置 → 数据与更新 → 回收站自动清空」可改为 60、90 天或永不），之后自动永久删除；打开回收站里的便签可以看到还剩几天。升级前就在回收站里的便签从升级后开始计时。自动清空在每日备份之后进行，所以被清掉的内容仍在当天的备份里。
- **正文待办**：直接添加待办、查看未完成数量和进度，完成项清理可撤销；文字、代码与清单自然混排。
- **一次性提醒**：每张便签一个提醒时间，应用后台调度，到点系统通知，中心提供打开和延后入口。
- **本地 MCP**：agent 可搜索、读写、整理便签和设置提醒，版本检查与可恢复历史保护已有内容。
- **直接换色**：工作台标题旁的调色盘支持主题色与自定义颜色，同步到桌面便签；换色不覆盖正文草稿。

## 日常使用

点击“新建便签”开始书写。正文支持 Markdown 标题、列表、任务项、引用、代码和表格，输入后自动保存。更多菜单提供模板、源码、导出、提醒、归档等操作。

独立便签标题栏保持紧凑：颜色圆点、标题、置顶、收起和更多菜单。置顶按钮与收起、更多按钮同尺寸，开启时为蓝色实心。点颜色圆点会弹出系统原生颜色菜单（不会被小窗口裁切），“自定义颜色…”打开系统取色器。收起后变为 `180 × 40` 胶囊，只保留颜色、标题、置顶和展开；点胶囊空白处或按 Enter / 空格展开，胶囊上的按钮不会误触展开或拖动。展开尺寸和自由位置分别保存。收起后编辑器会在约 45 秒后释放以节省内存，再次展开时重新载入；45 秒内重新展开会保留选区和撤销历史。拖动窗口边缘或四角调整大小，最小 `260 × 180`。

中心和桌面同一时间只有一个写入位置：展开的桌面窗口，或其余情况下的中心。编辑权移交前先保存对方草稿，保存失败则保持原状；中心 Tab 在会话内记住选区与滚动，跨编辑位置重新开始撤销历史。关闭中心仅隐藏窗口，不退出应用。托盘菜单提供中心入口、显隐、新建、设置、更新与退出。

**设置只在便签中心里打开**：中心左下角的设置按钮、托盘“设置”和 Cmd/Ctrl + , 都打开中心内的设置视图（中心收起时会先恢复）。分类为外观、窗口与便签、快捷键、集成、数据与更新。返回便签后 Tab、选中项、滚动位置、草稿和撤销历史都保持不变。

- **外观**：跟随系统 / 浅色 / 深色，所有窗口实时一致；跟随系统时随系统外观即时切换。便签自己的颜色是便签属性，深色模式下以该颜色为底色调呈现，不会改写便签颜色或内容。中心阴影、便签与胶囊阴影可选“关 / 细边 / 标准”（标准为系统窗口阴影，细边只有一圈细线、没有阴影）。减少动态会关闭窗口滑动与淡入。
- **窗口与便签**：开机自启、边缘自动吸附、悬停预览、共享屏幕时隐藏、恢复上次工作状态，以及新便签默认颜色、不透明度和置顶（只影响之后新建的便签）。
- **数据与更新**：数据目录、导出（当前便签或全部便签）、自动备份和检查更新。
- 设置会立即生效；写入失败会显示错误和“重试”，不会假装已保存。

**共享屏幕时隐藏**：开启后，所有 PinNote 窗口都会请求系统不要出现在截图、录屏和屏幕共享里。Windows 上可靠；macOS 上取决于录制软件，基于 ScreenCaptureKit 的较新工具仍可能录到，开会前最好先试一次。

**备份、恢复与导出**：应用运行时每天自动备份一次全部便签（内容没变就不备份），保留最近 14 份。在「设置 → 数据与更新」里可以立即备份，或选择一份恢复：恢复会先保存所有打开的编辑器，再把当前全部便签另存为一份“恢复前”备份（保留最近 3 份），然后替换并重启 PinNote。「导出全部」会在你选的位置新建一个文件夹，每张便签一个 Markdown 文件，归档的便签放在其中的「归档」文件夹里，回收站不导出。

**全局显隐只处理已放到桌面的普通便签**，不会打开整个便签库、归档或回收站。独立便签菜单可导出 `.md`。

### 待办和提醒

点击编辑区的“添加待办”，输入内容后按 Enter；也可以直接输入 `- [ ]`。点击复选区或在任务项内按 Cmd/Ctrl+Shift+Enter 切换完成状态。移除已完成项是一个可用 Cmd/Ctrl+Z 撤销的事务。代码围栏中的清单示例不计入进度。

通过更多菜单或待办旁的铃铛设置提醒。设置后出现时间标签，再次点击可修改或移除。Rust 后台每 15 秒检查到期时间，不依赖某个编辑窗口。

- 在托盘运行时提醒有效；完全退出时不会通知，下次启动处理错过的提醒。
- 归档暂停提醒，恢复清除旧安排，删除取消提醒。
- 到期操作入口在便签中心：打开便签、延后 10 分钟、清除提醒。系统通知本身不含跨平台操作按钮。
- 为避免重复通知，先持久化处理状态再调用系统；权限、勿扰模式或该间隙崩溃可能导致通知未展示，不保证必达。

### 快捷键

| 操作 | macOS | Windows |
| --- | --- | --- |
| 显示／隐藏桌面便签 | Cmd + Option + N | Alt + N |
| 新建便签 | Cmd + Option + Shift + N | Alt + Shift + N |
| 导出独立便签 | Cmd + S | Ctrl + S |
| 切换置顶 | Cmd + T | Ctrl + T |
| 切换源码 | Cmd + / | Ctrl + / |
| 打开设置 | Cmd + , | Ctrl + , |
| 加粗／斜体 | Cmd + B / I | Ctrl + B / I |
| 切换当前任务完成状态 | Cmd + Shift + Enter | Ctrl + Shift + Enter |

前两项为全局快捷键，可在设置中修改。其余在对应编辑窗口生效。源码与可视编辑不共享撤销栈，收起胶囊不切换编辑模式。

## 本地 MCP

安装 **Node.js 22+**，保持 **PinNote 1.2.0 或更新版本运行**，并从本仓库取得 [scripts/pinnote-mcp.mjs](../scripts/pinnote-mcp.mjs)。脚本无额外 Node 依赖，也可单独下载后保存。

在“设置 → 集成”启用本地 MCP。默认关闭；启用后默认只读、仅普通便签，可自行开启写入和全部范围。设置中可查看最近连接和 agent 修改记录：某张便签最新的一次 agent 修改且之后没有其他改动时，按钮为“撤销这次修改”；更早的记录为“恢复到此前版本”，会先说明影响（覆盖之后的修改、桌面便签收回中心）并保存当前草稿，替换前的版本会作为“恢复前的版本”留在列表里，可以再恢复回来。

MCP 客户端配置示例，替换为脚本的绝对路径：

```json
{
  "mcpServers": {
    "pinnote": {
      "command": "node",
      "args": ["/absolute/path/PinNote/scripts/pinnote-mcp.mjs"]
    }
  }
}
```

Windows 路径可写作 `C:/Users/you/PinNote/scripts/pinnote-mcp.mjs`。脚本自动查找应用数据目录中的 `com.pinnote.app/mcp-connection.json`；也可以把设置页的连接文件完整路径作为第二个参数，或设置 `PINNOTE_CONNECTION_FILE`。

支持 stdio MCP `2024-11-05`。桥接仅绑定 `127.0.0.1` 随机端口，每次启动换令牌，macOS 连接文件权限 `0600`。外部脚本只读连接描述，所有便签操作经过应用服务，不直接改写数据文件；应用未运行或集成关闭会返回明确错误。

工具包括 `search_notes`、`read_note`、`create_note`、`append_note`、`update_note`、`archive_note`、`trash_note`、`restore_note`、`set_reminder`、`cancel_reminder`、`open_note`。

修改前读取 `revision`，写入时带 `expectedRevision`。发生 `VERSION_CONFLICT` 时重新读取；`EDITOR_BUSY` 表示有未保存草稿，应等待保存。提醒 `at` 为未来的 Unix 毫秒时间戳。新建默认留在中心，只有明确调用 `open_note` 才请求桌面显示；其返回值表示请求已提交，不代表窗口显示确认。

agent 修改前版本与 UI 移除历史合计保留最近 100 次可恢复操作。设置中撤销或恢复后便签回到中心；永久删除会清除该便签恢复历史。

## 数据与兼容

应用标识仍为 `com.pinnote.app`。通过“设置 → 数据与更新 → 数据目录”打开目录。

| 文件 | 内容 |
| --- | --- |
| `notes.json` | 正文、生命周期、版本、外观、窗口、提醒及恢复历史 |
| `notes.before-v2.json` | 1.2 数据升级前备份（已有不同备份时另存唯一文件名） |
| `settings.json` / `templates.json` | 全局设置／自定义模板 |
| `integration.json` / `mcp-connection.json` | MCP 权限／当前连接描述 |
| `update-history.json` | 更新检查与通知去重记录 |
| `versions.json` | 每张便签的历史版本（每张最多 20 个） |
| `activity.json` | 记录概览用的每半小时编辑、新建和完成次数，保留约 400 天 |
| `backups/` | 每日自动备份 `notes-<时间>.json`，以及恢复前保留的 `notes-<时间>-before-restore.json` |

旧版多便签数据迁移前先备份并同步到磁盘，保留原 ID、正文、外观和位置；更早的 `note.json` 原文件继续保留。新格式将内容生命周期、桌面位置和内容版本分开管理。损坏文件不当作空库覆盖，保存失败保留草稿，退出前等待所有编辑器保存。

自动备份已经覆盖便签本身；需要连同设置一起备份时，从托盘退出，再复制整个数据目录。PinNote 为单实例应用，再次启动会唤起已运行的便签中心。 降级前先备份当前目录，旧版本不理解 1.2 生命周期与恢复历史。
